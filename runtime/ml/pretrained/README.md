# Дополнительная готовая NLI-модель

Демо обучает малый TF-IDF-классификатор и не использует этот артефакт.
Для явного нейросетевого режима сохранён вариант
`MoritzLaurer/deberta-v3-base-zeroshot-v2.0`: замороженный ONNX-энкодер
и 54 обучаемых коэффициента релевантности и тональности.

`student.joblib` содержит головы, настройки и историю обучения, около100КБ.
Большие веса не включены в него: ONNX738563249байт и токенизатор8649136байт
загружаются из Hugging Face либо локального пути по `student_encoder`
в `runtime/ml/config.yaml`, с проверкой SHA-256.

Чтобы установить готовую версию в registry, укажите
`bootstrap_model_path: pretrained/manifest.json` и перезапустите ML.
Установка проверяет размер и SHA-256, сохраняя пользовательские версии.
Для предварительной подготовки больших весов: `python runtime/ml/prepare.py`.
Кэш по умолчанию — `.local-data/ml/encoder-weights` при нативном запуске;
в Docker используется отдельный том. Обычный запуск демо этого не делает.

`nli_features.json` содержит600 наборов по3логита для фиксированного снимка.
В нём нет меток и итоговых предсказаний голов. Если изменились текст,
гипотезы, энкодер или токенизатор, выполняется настоящий NLI-инференс.

Вариант работает на CPU без PyTorch и GPU: измерялось около0,33с на новый
комментарий, примерно1,3ГБ RSS после прогрева и отдельный пик около2ГБ.
Эти числа относятся к NLI-процессу, а не к лёгкому демо или всем сервисам.

На отдельной ассистентской проверке120комментариев точность полярности
составила62,6%, macro-F1 0,566, MAE0,546 по87выданнымбаллам из91релевантного
комментария. Четыре отказа включены в ошибки полярности. Это не человеческий
gold; цель70% не подтверждена. Подробности корпуса — в корневом README.
