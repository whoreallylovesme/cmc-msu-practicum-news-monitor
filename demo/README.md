# Демонстрация и E2E

В `hn_1k.json` сохранены 1000 размеченных комментариев Hacker News,
в `hn_10k.json` — 10000. Меньший набор является подмножеством большего.
Все параметры запуска задаются в `1k.yaml` или `10k.yaml`; у команд есть
только `--config` для выбора файла.

## Запуск Docker

Из корня проекта, с работающим Docker и Compose:

```sh
python3 -m pip install -r demo/requirements.txt
python3 demo/start.py --config demo/1k.yaml
```

Скрипт собирает и запускает шесть сервисов, импортирует снимок, обучает
малый классификатор, проверяет результаты и оставляет дашборд работающим.
Teacher запускается по `with_teacher: true`, но его нейросеть для готовой
разметки не загружается. `with_teacher: false` оставляет пять основных сервисов.

Для полной выгрузки остановите меньшую версию и выберите другой YAML:

```sh
docker compose -p hn-monitor-demo-1k down
python3 demo/start.py --config demo/10k.yaml
```

Размеры используют отдельные проекты и тома: `hn-monitor-demo-1k` и
`hn-monitor-demo-10k`. Стандартные порты общие, поэтому одновременный запуск
требует разных значений `ports` в YAML.

Дашборд — [localhost:8080](http://127.0.0.1:8080/), единый Swagger —
[localhost:8080/gateway-docs](http://127.0.0.1:8080/gateway-docs).
Дашборд только читает результаты: динамика, поиск, комментарии и отчёт.
Запрос и модель задаются в корневом `config.yaml`; запись доступна через API.

## Настройки

- `dataset` — `1k` или `10k`;
- `with_teacher` — запуск шестого сервиса;
- `ports.api`, `ports.ui`, `ports.teacher` — опубликованные порты Docker;
- `native.base_port`, `native.data_dir` — порты и хранилище нативного запуска;
- `check.url` — адрес Web Master для отдельного E2E;
- `check.compare` — сравнение `hard_label` и `softmax`;
- остальные поля `check` задают сущность, источник, учителя и ограничения проверки.

Пароли остаются в `.env` или переменных `MONITOR_ADMIN_*` и `MONITOR_VIEWER_*`.
Скрипт Docker-запуска передаёт проверке фактический адрес и учётные данные.
Для отдельного E2E используйте правильный `check.url` и экспортируйте свои пароли.

```sh
python3 demo/e2e.py --config demo/1k.yaml
```

Размер YAML должен совпадать с запущенным снимком. Проверяются полный импорт
без дублей, отпечатки меток, 401/403 для ролей, обучение, оценки всех строк,
число упоминаний, временная динамика, комментарии, HTML-отчёт, инференс нового
текста и `incremental → skipped` без новой версии. При `check.compare: true`
дополнительно обучается `softmax`. CI выполняет ту же проверку для обоих размеров
с пятью основными контейнерами, без скачивания NN-весов.

Метки A–F и их происхождение хранятся в строках датасета. Это подготовленная
silver-разметка для демонстрации, а не независимый человеческий эталон.
Модель использует метки этого набора без отдельного файла ручных корректировок.
Обучение и проверка разделяются по тредам; заданный процент точности не требуется.
JSON-результат идёт в stdout, сообщения о ходе работы — в лог; артефакты прогонов
в репозиторий не записываются.

## Нативный запуск

В окружении Python 3.12 с зависимостями из корневого `requirements.txt`:

```sh
python3 demo/run.py --config demo/1k.yaml
```

При `native.base_port: 8100` Web Master работает на 8103, UI — на 8104,
Teacher — на 8105. Для отдельного E2E сделайте копию YAML, задайте в ней
`check.url: http://127.0.0.1:8103` и передайте эту копию через `--config`.
`native.data_dir: null` выбирает отдельное локальное хранилище по размеру набора.

## Остановка

```sh
docker compose -p hn-monitor-demo-1k down
docker compose -p hn-monitor-demo-10k down
```

Обычный `down` сохраняет тома с данными и моделями.
