# Демонстрация и E2E

Два размеченных снимка Hacker News содержат 1000 и 10000 комментариев:
`hn_1k.json` — подмножество `hn_10k.json`. Для быстрого показа по умолчанию
выбирается меньший файл. Из корня проекта, с работающим Docker и Compose:

```sh
python3 demo/start.py
```

Для полного снимка:

```sh
python3 demo/start.py --dataset 10k
```

Launcher собирает и запускает пять сервисов, передаёт выбранный файл через
`MONITOR_DATASET_PATH` и выполняет `demo/e2e.py` с тем же `--dataset`.
Размеры используют отдельные проекты Compose `hn-monitor-demo-1k` и
`hn-monitor-demo-10k`, чтобы их сохранённые данные не смешивались.
Перед переключением остановите предыдущий проект: стандартные порты общие.

Готовая модель не требуется: E2E импортирует весь выбранный снимок и
обучает малый `hard_label` классификатор по меткам из самого датасета.
Сервис Teacher и веса нейросетей для этого пути не используются.
Проверяются отпечатки размеченного контекста, полный импорт без дубликатов,
роли, обучение, оценки всех строк, число упоминаний, график, комментарии,
HTML-отчёт, предсказание нового текста и пропуск повторного обучения без
новой версии. Ожидаемое число упоминаний вычисляется из выбранного файла
с теми же правилами сопоставления, что использует приложение.
Результаты печатаются в терминал; файлы метрик в репозиторий не записываются.
Интернет может использоваться при сборке; «снимок» означает источник данных HN.

UI — [localhost:8080](http://127.0.0.1:8080/), Swagger —
[gateway-docs](http://127.0.0.1:8080/gateway-docs).
Порты задаются экспортированными `MONITOR_API_PORT`, `MONITOR_UI_PORT` и
`MONITOR_TEACHER_PORT`; учётные данные — существующими `MONITOR_ADMIN_*`
и `MONITOR_VIEWER_*`. CLI и Compose должны получать одно окружение.

Повторить E2E на уже запущенных сервисах и сравнить два малых классификатора:

```sh
python3 demo/e2e.py --dataset 1k --url http://127.0.0.1:8081 --compare
python3 demo/e2e.py --dataset 10k --url http://127.0.0.1:8081 --compare
```

Запускайте команду с тем размером, который выбран у работающих сервисов.
`--compare` дополнительно обучает малый `softmax` классификатор. CI запускает
тот же E2E отдельно для обоих размеров, без профиля Teacher.
Каждая строка датасета содержит метку A–F, имя объекта `label_entity`,
источник `label_source` и SHA-256 контекста `label_fingerprint`.
Происхождение конкретной метки указано в самой строке; это silver-разметка
для демонстрации процесса, а не независимый человеческий эталон качества.
Обучающий и проверочный наборы разделяются по веткам обсуждений;
E2E не требует достижения заданного процента точности на этих метках.

Для нативного запуска в окружении с зависимостями:

```sh
python3 demo/run.py --dataset 1k --data-dir .local-data/demo-1k
python3 demo/e2e.py --dataset 1k --url http://127.0.0.1:8103
```

Вторую команду выполняют в другом терминале. Для большего снимка выберите
`--dataset 10k` и отдельную папку данных. Без аргумента `demo/run.py`
сохраняет путь из конфигурации или окружения. Все три CLI находят корень
по своему пути и допускают запуск абсолютным путём из другой рабочей папки.

Отдельный нейросетевой Teacher нужен только для явных экспериментов:

```sh
python3 demo/start.py --dataset 1k --with-teacher
```

Это включает профиль `training`, сохраняя источник меток `dataset` и малый
классификатор для E2E. Teacher Swagger доступен на
[localhost:8082/docs](http://127.0.0.1:8082/docs).
У `demo/run.py --with-teacher` отдельный учитель использует порт 8105.

Остановить выбранное Docker-демо без удаления сохранённых томов:

```sh
docker compose -p hn-monitor-demo-1k down
docker compose -p hn-monitor-demo-10k down
```
