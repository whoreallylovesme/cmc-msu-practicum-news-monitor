# Демонстрация и E2E

`hn_1k.json` содержит 1000 размеченных комментариев Hacker News,
`hn_10k.json` — 10 000. Первый набор является подмножеством второго.
Готовые метки позволяют запустить конвейер без тяжёлой модели учителя.
Нейросетевому ученику нужны закреплённые веса ModernBERT-large: первый запуск
скачивает около 0,79 ГБ, следующие используют проверенный кэш.

Полное обучение на 10k с текущими настройками заняло 61 минуту на M3 Pro
с Metal. Docker использует CPU; время его полного обучения отдельно не
измерялось. Оба размера дополнительно используют 6322 человеческих примера
NewsMTSC, поэтому 1k сокращает только часть HN. `check.timeout: 21600` даёт
до шести часов на ожидание обучения и каждый HTTP-запрос; это лимит ожидания,
а не обещание длительности. Инференс выполняется после обучения.

## Запуск

Из корня проекта с работающим Docker и Compose:

```sh
python3 -m pip install -r demo/requirements.txt
python3 demo/start.py --config demo/1k.yaml
```

Команда запускает шесть сервисов, импортирует снимок, обучает одного ученика,
проверяет API и оставляет дашборд работающим. `with_teacher: true` включает
Teacher профилем Compose `training`; его GGUF-веса для `teacher: dataset`
не загружаются. `with_teacher: false` оставляет пять основных сервисов.

Дашборд: [localhost:8080](http://127.0.0.1:8080/).
Общий Swagger: [localhost:8080/gateway-docs](http://127.0.0.1:8080/gateway-docs).
Учётные записи по умолчанию: `admin / admin-demo`, `viewer / viewer-demo`.
Свои пароли задайте в `.env` или переменных `MONITOR_ADMIN_*`, `MONITOR_VIEWER_*`.

Для полной выгрузки остановите меньшую версию:

```sh
docker compose -p hn-monitor-demo-1k down
python3 demo/start.py --config demo/10k.yaml
```

Проекты и тома разделены: `hn-monitor-demo-1k`, `hn-monitor-demo-10k`.
Стандартные порты общие; для параллельного запуска измените `ports` в YAML.
Остановка полной версии: `docker compose -p hn-monitor-demo-10k down`.
Обычный `down` сохраняет данные и модели.

## Настройки и повторная проверка

Все параметры команд находятся в `1k.yaml` или `10k.yaml`:

| Поле | Назначение |
|---|---|
| `dataset` | Снимок `1k` или `10k` |
| `with_teacher` | Запустить шестой сервис |
| `ports.api`, `ports.ui`, `ports.teacher` | Порты Docker |
| `native.base_port`, `native.data_dir` | Порты и хранилище нативного запуска |
| `check.url` | Web Master для отдельного E2E |
| `check.training_limit`, `check.timeout` | Лимит HN-примеров; ожидание обучения и HTTP в секундах |

Запрос и алиасы, источник данных и ID модели дашборда задаются в корневом
`config.yaml`. В ML используется один ученик; источники меток — только
`dataset` и `service`. Параметры обучения находятся в `runtime/ml/config.yaml`,
GGUF-модель и llama.cpp — отдельно в `runtime/teacher/config.yaml`.

```sh
python3 demo/e2e.py --config demo/1k.yaml
```

Размер YAML должен совпадать с запущенным снимком. Проверяются полный импорт
без дублей, отпечатки контекста, права 401/403, передача меток всех строк,
обучение, предсказания всех комментариев, аналитика, временные периоды,
HTML-отчёт, новый текст и `incremental → skipped` без новой версии.
Отдельный E2E использует `check.url`; при своих паролях экспортируйте их для CLI.

Метки HN — подготовленная разметка с указанным происхождением, а не независимый
человеческий эталон. Согласие с ними оценивает дистилляцию. Для отдельной
проверки на человеческих метках предназначен [quality/README.md](quality/README.md).
Там используются NewsMTSC, Airline и Weather Sentiment; результаты нельзя автоматически
переносить на HN и пять уровней интенсивности отношения.

CI выполняет E2E для обоих размеров с шестью контейнерами и CPU PyTorch.
Он использует тот же ModernBERT-large с временным конфигом: одна эпоха,
контекст 32 токена, батч 8, максимум два шага оптимизатора.
Метки всех 1k/10k строк проходят через конвейер, и все строки
получают предсказания. Такой запуск проверяет контракты и интеграцию; его метрики
не являются доказательством качества. Веса ученика скачиваются, GGUF-учитель — нет.
Рабочая конфигурация обучения этим сокращённым бюджетом не заменяется.

## Нативный вариант

Python 3.12, из корня проекта:

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python demo/run.py --config demo/1k.yaml
```

При `native.base_port: 8100` Web Master работает на 8103, UI — на 8104,
Teacher — на 8105. Для отдельного E2E сделайте копию YAML и задайте в ней
`check.url: http://127.0.0.1:8103`. `native.data_dir: null` выбирает отдельное
хранилище по размеру набора. Для готовой разметки llama.cpp не запускается;
для `service` задайте доступный бинарник b12192 в конфиге Teacher.
Нативный запуск останавливается через Ctrl+C.

JSON-результат E2E выводится в stdout, сообщения о ходе работы — в журнал.
Веса, базы, логи и результаты проверок находятся в томах или `.local-data/`,
без добавления артефактов прогонов в репозиторий.
